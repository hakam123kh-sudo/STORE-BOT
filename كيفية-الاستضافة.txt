استضافة البوت 24/7 (بدون كمبيوتر)
==================================
بمجرد الاستضافة، البوت يشتغل على سيرفر سحابي — كل أجهزتك ممكن تكون مطفية
والزبون يطلب ويستلم الكتاب عادي.

البوت يستعمل «long polling» فما يحتاج رابط عام ولا دومين — يشتغل على أي استضافة تشغّل بايثون.


الخيار (أ): Koyeb — سحابي، مجاني (الأنسب لو عندك بطاقة)
--------------------------------------------------------
1) أنشئ حساب GitHub مجاني، وارفع محتويات مجلد deploy كمستودع (Repository).
   (store_bot.py + Dockerfile + requirements.txt + مجلد files + Procfile)
2) أنشئ حساب على koyeb.com (مجاني).
3) Create Service → Deploy from GitHub → اختر المستودع.
   Koyeb يكتشف Dockerfile تلقائيًا. اختر نوع الخدمة: Worker.
4) في Environment variables أضف (من ملف .env.example):
   BOT_TOKEN        = التوكن حقك
   OWNER_CHAT_ID    = 7784517251
   PRICE            = 50 د.ل / 6$
   BOOK_TITLE       = مدير السوشيال ميديا بالذكاء الاصطناعي
   BANK_INFO        = (بيانات التحويل — انسخها من .env.example)
5) Deploy. خلاص، البوت شغّال 24/7.

ملاحظة: بعض الاستضافات تطلب بطاقة للتحقق. لو ما عندك بطاقة تشتغل، استعمل الخيار (ب).


الخيار (ب): هاتف أندرويد قديم عبر Termux — مجاني تمامًا، بدون بطاقة
------------------------------------------------------------------
هاتف قديم يبقى شاحن وموصول واي-فاي = سيرفر مصغّر مجاني.
1) ثبّت تطبيق Termux (من متجر F-Droid).
2) داخل Termux:  pkg update && pkg install python -y
3) انسخ مجلد deploy إلى الهاتف، وادخل إليه:  cd ~/deploy
4) pip install requests
5) أنشئ ملف keys.json فيه التوكن والإعداد (زي النسخة اللي على الكمبيوتر)،
   أو صدّر المتغيّرات. ثم شغّل:  python store_bot.py
6) خلّي الهاتف شغّال وموصول بالإنترنت. (لإبقائه يعمل: termux-wake-lock)


أيًّا كان الخيار: البوت هو نفسه، ونفس تجربة الزبون (طلب → إثبات → قبولك → تسليم تلقائي).
لأي خطوة احتجت مساعدة فيها، قل لي وأمشّيك خطوة بخطوة.
